# Инфо-табло расписаний

Информационное табло с расписанием приёма врачей для поликлиники и панель администратора к нему.

## Запуск

Нужен установленный [Node.js](https://nodejs.org/).

Двойным щелчком по `Сначала запусти этот файл.bat` — он поставит зависимости и поднимет сервер. Либо вручную:

```bash
npm install
npm start
```

После запуска:

- табло — http://localhost:3000/
- панель администратора — http://localhost:3000/admin.html

Рядом лежат ярлыки `ОбычнаяПанель.url` и `АдминПанель.url` — открывают то же самое.

## Что умеет

**Табло**

- отделения с карточками врачей и расписанием на неделю;
- колонка текущего дня обведена рамкой;
- показ остатка талонов;
- автоповорот между отделениями, если их больше, чем помещается;
- масштаб подбирается под экран автоматически;
- три фоновых темы.

**Панель администратора**

- отделения и врачи: добавление, удаление, порядок показа, группировка по специальностям;
- расписание на выбор — по дням недели либо по чётным и нечётным числам месяца;
- два режима приёма: по талону и без талона;
- скрытие отдельного врача без удаления данных;
- сохранение именованных конфигураций с возможностью вернуться к любой из них;
- запись текущих настроек обратно в `config.js`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `server.js` | сервер: раздаёт страницы, хранит данные, работает с конфигурациями |
| `index.html`, `app.js`, `styles.css` | табло |
| `admin.html`, `admin.js`, `admin.css` | панель администратора |
| `shared.js` | общие правила данных для сервера, табло и панели |
| `config.js` | настройки и демо-данные |

Данные сохраняются в папку `data` рядом с программой: `current.json` — то, что показывает табло, `configs.json` — сохранённые конфигурации. Папка создаётся при первом сохранении и в репозиторий не попадает.

## Настройки через переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | порт сервера |
| `ADMIN_TOKEN` | пусто | если задан, запись требует заголовок `X-Admin-Token` |
| `ALLOW_REMOTE_WRITES` | `false` | разрешить запись не только из локальной сети |
| `MAPSOFT_BASE` | — | адрес внешнего источника расписаний |
| `MAPSOFT_AUTH_MODE` | `token` | `token` или `basic` |
| `MAPSOFT_TOKEN`, `MAPSOFT_USER`, `MAPSOFT_PASS` | пусто | доступ к внешнему источнику |

По умолчанию менять расписание можно только с этого компьютера или из локальной сети.
